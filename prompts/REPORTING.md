# Reporting

## LLM eval

Source of truth: `projects/redteam/out/UNIFIED_REPORT.md` plus per-layer JSON.
Include n, judge type, spend, target id, attacker id, date.

## Web / backend

Shannon-style: finding, evidence path, reproduction, severity, not a
screenshot-only claim.

## Recon

Cite sources. No implied authorization to scan what you only looked up.

## What never goes in the report chat

Raw tokens, cookies, private keys, full jailbreak strings longer than needed
to identify the category. Point to files instead.
